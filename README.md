# S.T.U.N. Runner (Atari Games, 1989) — full decompilation

Goal: a complete source reverse-engineering of the S.T.U.N. Runner arcade
game that **assembles back into the original ROM images byte for byte**, with
human-friendly labels (local labels where they help), and the game's assets
(sprites, tunnel graphics, fonts, sounds) extracted to editable forms (PNG,
meshes, data files) that the build re-embeds into the binary. Same spirit as
the Spindizzy decomp (`~/git-repos/personal/spindizzy`, docs/26-assembler-source.md).

The ROMs themselves live **outside this repository** and are never committed.

Seeded 2026-11-04 by Vera from Jesus's brief; the kickoff room fills in the
hardware map, toolchain choice, build pipeline and milestones.
